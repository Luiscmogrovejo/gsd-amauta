# ADR-000: Template

> This is the template for Architecture Decision Records. Copy this file and
> fill in the sections when creating a new ADR. Number sequentially (001, 002, ...).
> Format based on Michael Nygard's ADR template.

## Status

proposed | accepted | deprecated | superseded by ADR-NNN

## Context

What is the issue that we are seeing that is motivating this decision or change?
What forces are at play (technical, business, social, project)?

## Decision

What is the change that we are proposing and/or doing?
State the architecture decision in full sentences, with active voice.

## Consequences

What becomes easier or more difficult to do because of this change?
List both positive and negative consequences.

## Alternatives considered

What other options were evaluated? For each alternative:
- **Alternative 1: Name** -- brief description
  - Pros: what would have been gained
  - Cons: why it was rejected
