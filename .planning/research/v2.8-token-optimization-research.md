## Key Findings

1. **Claude API Prompt Caching** — 90% cost reduction on repeated prefixes. Highest ROI. Requires stable prefix ordering (tools → system → messages).
2. **Structured Context Handoffs** — RPETDContext Pydantic model (~400 tokens) replaces full context forwarding (~5K-20K tokens). 12-50x reduction per transition.
3. **Hash-Based Staleness Detection** — SHA-256 + git diff + schema version hashing. Skip unchanged files (60-80% typical). Selective refresh only.
4. **Caveman-Style Description Compression** — 40-60% more info per 500-char description. Strip grammar, preserve facts. LLMLingua-2 for token-level compression.
5. **Semantic Cache Layer** — pgvector cosine similarity >= 0.90 for cached LLM responses. Up to 68% fewer redundant calls.
6. **Tiered Model Routing** — R/P → Sonnet (reasoning), E → Sonnet (coding), T/D → Haiku ($1/MTok). 30-50% cost on T/D phases.

## Attention Residuals Application-Layer Lessons

- Selective aggregation > uniform accumulation (weight context per phase need)
- Block-level boundaries bound context growth (R+P block vs E+T+D block)
- Original signal persists throughout (task description verbatim in every phase)
