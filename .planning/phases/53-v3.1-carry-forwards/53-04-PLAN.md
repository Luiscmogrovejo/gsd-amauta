## Goal

Inject Phase 47 hydration automatically into every subagent prompt at spawn time. Operator no longer manually invokes `gsd-tools agent-hydrate` — the workflow runner does it before each Task(). Kill switch preserves opt-out for environments where hydration is unwanted.

## Verification Criteria

1. `grep -c "GSD_HYDRATE_TASKS" get-shit-done/workflows/execute-phase-legacy.md >= 1`
2. `grep -c "HYDRATE_CMD" get-shit-done/references/cli-variables.md >= 1`
3. `grep -c "agent-hydrate" get-shit-done/workflows/execute-phase-legacy.md >= 1`
4. `grep -c "current_context\|Current context" get-shit-done/workflows/execute-phase-legacy.md >= 1`
5. Sharded step file (`step-04-spawn-executors.md` or equivalent Task-spawning step) contains the same hook shell block
6. `node --test tests/workflow-hydration-hook.test.cjs` exits 0

## must_haves

- Shell hook block injected BEFORE each `Task()` invocation in workflow .md files
- Hook reads HYDRATE_CMD from cli-variables.md (LEARN-07 reuse)
- Kill switch: `GSD_HYDRATE_TASKS=off` short-circuits to empty HYDRATION
- HYDRATION nonempty → injected as `<current_context>` block in agent prompt
- Phase 47 `services/agent_hydrator.py` + `services/agent_hydrate_cli.py` UNCHANGED (hook calls but doesn't modify)
- Phase 41 sharded workflow structure preserved (only ADD shell-out, don't rearrange)
- Idempotency: running the hook twice produces same output (Phase 47 hydration is deterministic for unchanged sources)
