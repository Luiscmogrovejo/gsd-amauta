## Goal

Add `--upgrade` and `--uninstall` to `bin/init.cjs` (Phase 44 was install-only). Reuse Phase 44's per-step result schema, worst-of combinator, and frozen step naming pattern. The 7-step install flow stays unchanged.

## Verification Criteria

1. `grep -c "args\.includes('--upgrade')" bin/init.cjs >= 1`
2. `grep -c "args\.includes('--uninstall')" bin/init.cjs >= 1`
3. Phase 44 7-step install vocabulary still present (`grep -c "buildStepResult('detect_ides'" bin/init.cjs >= 1`)
4. `node bin/init.cjs --upgrade --json --skip-daemon --backend sqlite` exits 0 with structured per-step results
5. `node bin/init.cjs --uninstall --json --dry-run` exits 0 (dry-run safe)
6. `node --test tests/init-upgrade-uninstall.test.cjs` exits 0

## must_haves

- New flags: `--upgrade` (version-aware migration), `--uninstall` (remove Amauta), `--dry-run` honored for both
- 12 new step names (FROZEN per CONTEXT §Area 2):
  - upgrade (6): `detect_current_version`, `compute_migration_delta`, `apply_upgrade_migrations`, `update_install_record`, `restart_daemon`, `run_assertions`
  - uninstall (6): `read_install_record`, `remove_skills`, `remove_agents`, `remove_generated_config`, `clear_install_record`, `post_uninstall_verify`
- Phase 44 7-step install flow + existing flags (`--skip-install`, `--skip-daemon`, `--opencode`, `--claude`, `--backend`, `--force`, `--json`, `--yes`, `--tools`, `--force-migrate`) UNCHANGED
- Worst-of exit code: 0 if all pass/skip/warn, 1 if any step fails
- Uninstall preserves user-authored: `.planning/`, `agents/` (or `get-shit-done/agents/`), `skills/`, `tests/`, source files
- Idempotency: re-run of upgrade at same version → all skip, exit 0
