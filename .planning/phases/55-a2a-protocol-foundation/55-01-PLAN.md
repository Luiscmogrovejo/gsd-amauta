# Plan 55-01: A2A Migration 024 — a2a_messages table

## Objective

Create the `a2a_messages` PG table (migration 024) that serves as the
persistent store for all A2A request/response/error/retry messages.
This is a pure schema migration — no Python services in this plan.

## Locked Schema (from planning_context gray-area decisions)

Columns (exact order):
- `correlation_id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
- `parent_correlation_id UUID` (nullable — for Phase 56 threading)
- `from_agent VARCHAR(64) NOT NULL`
- `to_agent VARCHAR(64) NOT NULL`
- `capability VARCHAR(128) NOT NULL`
- `payload JSONB NOT NULL DEFAULT '{}'::jsonb`
- `kind VARCHAR(16) NOT NULL` — CHECK IN ('request','response','error','retried')
- `status VARCHAR(64) NOT NULL DEFAULT 'pending'`
- `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`
- `responded_at TIMESTAMPTZ` (nullable — set when kind='response' or kind='error')

Index: `CREATE INDEX IF NOT EXISTS idx_a2a_messages_to_agent_status ON a2a_messages (to_agent, status)`

Frozen `kind` vocabulary: `request | response | error | retried`
(CHECK constraint at DB level — enforces before any write)

## Frozen conventions (mirrors migration 021-party-sessions.sql)
- `BEGIN; ... COMMIT;` transaction wrap
- `IF NOT EXISTS` guard on CREATE TABLE
- `COMMENT ON TABLE` with phase/requirement reference
- DOWN file: `DROP TABLE IF EXISTS a2a_messages CASCADE;`

3. **Double-run idempotency:** `IF NOT EXISTS` guards on both CREATE TABLE and CREATE INDEX ensure safe re-run. Risk: low.

## must_haves

Non-negotiable invariants that MUST be preserved across this plan's execution:

- **NEW table — never alter `agent_messages`:** Migration 024 creates `a2a_messages`, a distinct PG table. The Phase 38 `agent_messages` table is NOT touched. Verified by absence of any `ALTER TABLE agent_messages` in either UP or DOWN file.
- **`correlation_id` is PRIMARY KEY (not unique-on-anything-else):** Phase 56 `parent_correlation_id` thread chains MUST be able to reuse `correlation_id` lookups; making it PK guarantees a single canonical row per id. Verified by `grep -E "correlation_id[[:space:]]+UUID[[:space:]]+PRIMARY KEY" migrations/024-a2a-messages.sql`.
- **Frozen `kind` vocabulary (4 values only):** request / response / error / retried. Adding a 5th value at this layer would silently break Phase 56's circuit breaker error vocabulary (which goes in `payload`, not `kind`). Locked by CHECK constraint, asserted by VC4 above.
- **Idempotent UP migration:** `IF NOT EXISTS` on both CREATE TABLE and CREATE INDEX. Required because Phase 55 may re-run during gap closure or recovery.
- **DOWN migration cleanly reverses UP:** DOWN drops only what UP creates — table + index. No collateral damage to other schemas. Verified by line-count parity check (DOWN ≤ 1.5x UP lines).
