# Plan 17-03: Full Field Sync + Reconcile Command

## Objective

Fix dual-write to mirror ALL 7 dropped fields to PG, add a `amauta reconcile` command that diffs tasks.json vs PG and reports/fixes field-level mismatches, and add a PG migration for the missing columns.

## Why Wave 2

This plan depends on Plan 17-01 (TOCTOU fix ensures reconcile reads consistent state) and Plan 17-02 (retry flush ensures PG has latest data before reconciliation). Without those foundations, reconcile would report false positives from stale retries and TOCTOU races.

## Context

- `task_upsert()` in pg_store.py L643-741 maps 32 fields from JSON to PG but drops 7:
  - `doc_refs` (list of file/URL references)
  - `risks` (list of risk objects)
  - `validation_checklist` (list)
  - `estimated_hours` (float)
  - `due_date` (string, ISO format)
  - `sprint` (string)
  - `children` (list of child task IDs)
- gsd_tasks PG schema (001-init.sql L64-121) does NOT have columns for these 7 fields
- Need migration 007 to add columns, then update task_upsert to include them
- No `amauta reconcile` command exists -- no way to check JSON/PG sync

## Risks

1. **PG migration on production data** -- Mitigation: all new columns are nullable with defaults, ADD COLUMN is non-blocking in PG
2. **Reconcile with large dataset (689 tasks)** -- Mitigation: batch PG reads (SELECT WHERE id IN (...) in chunks of 50)
3. **JSONB columns vs Python lists** -- Mitigation: use `json.dumps()` for list fields (same pattern as success_criteria, deliverables)
4. **Reconcile fix direction** -- Mitigation: JSON is always source of truth. Reconcile only writes JSON->PG, never PG->JSON. Add `--dry-run` flag.

1. Add `cmd_reconcile(args)` to amauta.py:
   ```python
   def cmd_reconcile(args):
       """Diff tasks.json vs PG gsd_tasks. JSON is source of truth."""
       data = load()
       items = data["items"]

       # Connect to PG
       db_url = _mem_db_url()
       if not db_url:
           print("ERROR: No PG connection available. Set GSD_POSTGRES_URL."); sys.exit(1)

       import psycopg2
       import psycopg2.extras
       conn = psycopg2.connect(db_url)

       # Read all PG tasks
       with conn.cursor(cursor_factory=psycopg2.extras.RealDictCursor) as cur:
           cur.execute("SELECT * FROM gsd_tasks")
           pg_tasks = {row["id"]: dict(row) for row in cur.fetchall()}

       json_ids = {i["id"] for i in items}
       pg_ids = set(pg_tasks.keys())

       # Find discrepancies
       missing_in_pg = json_ids - pg_ids
       extra_in_pg = pg_ids - json_ids  # tasks in PG but not in JSON (shouldn't happen normally)

       # Field-level comparison for tasks in both
       field_mismatches = []
       compare_fields = ["title", "status", "priority", "assigned_to", "claimed_by",
                         "type", "description", "details", "phase", "plan",
                         "doc_refs", "risks", "validation_checklist",
                         "estimated_hours", "due_date", "sprint"]
       for item in items:
           if item["id"] in pg_tasks:
               pg = pg_tasks[item["id"]]
               for field in compare_fields:
                   json_val = item.get(field)
                   pg_val = pg.get(field)
                   # Normalize for comparison (JSONB strings vs Python lists)
                   if isinstance(json_val, (list, dict)):
                       json_val = json.dumps(json_val, sort_keys=True)
                   if isinstance(pg_val, (list, dict)):
                       pg_val = json.dumps(pg_val, sort_keys=True)
                   if str(json_val or "") != str(pg_val or ""):
                       field_mismatches.append((item["id"], field, json_val, pg_val))

       # Report
       print(f"Reconcile: {len(json_ids)} JSON tasks, {len(pg_ids)} PG tasks")
       print(f"  Missing in PG: {len(missing_in_pg)}")
       print(f"  Extra in PG: {len(extra_in_pg)}")
       print(f"  Field mismatches: {len(field_mismatches)}")

       if missing_in_pg:
           for tid in sorted(missing_in_pg)[:20]:
               print(f"    + {tid} (not in PG)")
       if field_mismatches:
           for tid, field, jv, pv in field_mismatches[:20]:
               print(f"    ~ {tid}.{field}: JSON={str(jv)[:40]} vs PG={str(pv)[:40]}")

       # Fix mode
       if getattr(args, "fix", False) and (missing_in_pg or field_mismatches):
           # Import pg_store for upsert
           sys.path.insert(0, str(Path(__file__).parent / "services"))
           from pg_store import PGStore
           store = PGStore(dsn=db_url)

           fixed = 0
           for item in items:
               if item["id"] in missing_in_pg or any(m[0] == item["id"] for m in field_mismatches):
                   store.task_upsert(item)
                   fixed += 1
           print(f"\nFixed: {fixed} tasks synced to PG")
       elif not missing_in_pg and not field_mismatches:
           print("\n  JSON and PG are in sync.")
       else:
           print(f"\n  Run with --fix to sync JSON -> PG")

       conn.close()
   ```
