# Plan 22-01: Archive, Reconcile, and RLM Test Suites

## Objective

Create three test files covering `cmd_archive`, `cmd_reconcile`, and the RLM wiring layer (`_rlm_query` + `_rpetd_phase_enrich`). All tests mock filesystem, PG, and HTTP to run fast without infrastructure.

## Context

- Source under test: `amauta.py` functions -- `cmd_archive`, `cmd_reconcile`, `_rlm_query`, `_rpetd_phase_enrich`, `_last_enrichment_ts`
- Existing test patterns: `tests/test_gates.py` (pure function tests, unittest), `tests/test_data_integrity.py` (SQLite + mock patterns)
- Environment guards: `GSD_AMAUTA_NO_AUTO_START=1`, `PYTEST_CURRENT_TEST=1` already used across test suite
- `cmd_archive` reads/writes `tasks.json` and `tasks-archive.json` via `load()` / `save()` / `_load_archive()` / `_save_archive()`
- `cmd_reconcile` connects to PG via psycopg2, compares 37 compare_fields (plus 5 rpetd_json_to_pg mappings)
- `_rlm_query` uses `urllib.request` to POST to localhost RLM service
- `_rpetd_phase_enrich` combines RLM + PG memory; checks `ENRICHMENT_DEDUP_WINDOW` (300s)
- FIX-09: `cmd_archive` removes archived child IDs from parent.children arrays
- FIX-05: `cmd_reconcile` loads `tasks-archive.json` to cross-reference

## Risks & Mitigations

1. **Import side effects** -- `amauta.py` has module-level init. Mitigate: `GSD_AMAUTA_NO_AUTO_START=1` + `PYTEST_CURRENT_TEST=1` env vars set before import (pattern from test_gates.py).
2. **psycopg2 import** -- `cmd_reconcile` imports psycopg2 inline. Mitigate: Mock at `builtins.__import__` level or patch `psycopg2.connect` after it's imported.
3. **Filesystem interaction in archive tests** -- `cmd_archive` uses `_file_lock()`. Mitigate: Patch `_file_lock` with a no-op context manager.
4. **RLM port collision** -- Tests might hit real RLM if running. Mitigate: All HTTP calls are mocked via `urllib.request.urlopen` patches.
