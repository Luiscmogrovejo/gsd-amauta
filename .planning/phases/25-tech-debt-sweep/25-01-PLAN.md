# Plan 25-01: Ghost Elimination + Plan-to-Tasks Default Fix

## Objective

Close DEBT-01 (cmdInitPhaseOp ghost fallback) and DEBT-02 (plan-to-tasks registration gap) with surgical fixes and comprehensive regression tests.

### DEBT-01 Analysis

The ghost fallback was already eliminated at the `findPhaseInternal` level in Phase 16 (milestone-scoped resolver). The existing tests in `16-init-resolver.test.cjs` verify `findPhaseInternal` returns null for ghosts. However, no test verifies the ghost is dead through the `cmdInitPhaseOp` entry point (which is what `init discuss-phase`, `init plan-phase`, and `init execute-phase` actually call), and no test uses a v2.8 context. DEBT-01 requires a regression test through the init.cjs surface with `current_milestone: v2.8`.

### DEBT-02 Analysis

Root cause: `execute-phase.md` line ~133 has `"${GSD_P_AUTO_TASK:-false}" = "false"` which defaults to "false" when the env var is unset, causing plan-to-tasks to be SKIPPED for ALL phases >= 14 unless the user explicitly sets `GSD_P_AUTO_TASK=true`. The `planToTasks` function in gsd-tools.cjs correctly treats the env var as a kill switch (only skips when explicitly set to "false"), but the bash guard in the workflow inverts the default. Fix: change the bash default from "false" to "true".

## must_haves

- cmdInitPhaseOp with v2.8 context does NOT return v2.3/v2.4 ghost directories
- execute-phase.md defaults GSD_P_AUTO_TASK to "true" (plan-to-tasks runs by default)
- Regression tests for both DEBT-01 and DEBT-02

## Verification

```bash
node --test tests/25-debt-sweep.test.cjs 2>&1 | tail -5
# All DEBT-01 and DEBT-02 tests pass
grep -c 'GSD_P_AUTO_TASK:-true' get-shit-done/workflows/execute-phase.md
# Returns >= 1
```
