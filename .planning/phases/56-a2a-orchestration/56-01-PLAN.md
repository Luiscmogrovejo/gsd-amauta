# Plan 56-01: A2A Circuit Breaker — per agent-pair Valkey state machine

## Objective

Implement a per-`(from_agent, to_agent)` circuit breaker backed by Valkey.

State machine: `CLOSED → OPEN (3 failures in 60s) → HALF_OPEN (60s elapsed) → CLOSED (probe success) | OPEN (probe fail)`.

Failure attribution: `A2ATimeoutError` and `A2AAgentUnavailableError` count; `A2APayloadInvalidError` and `A2AUnknownCapabilityError` do NOT (they are caller errors, not target-agent problems).

The breaker check fires inside `send_request()` in `services/a2a_client.py` via a new `_check_breaker(from_agent, to_agent)` helper — BEFORE the PG INSERT. When the breaker is OPEN, `A2AAgentUnavailableError` is raised immediately (no network round-trip, no PG write).

Valkey key format: `a2a:breaker:<from_agent>:<to_agent>` — JSON `{state, failure_count, opened_at}`.
TTL on failure-count: 60s auto-reset (sliding window).

This plan does NOT touch the daemon HTTP layer. Plan 56-03 adds the `/a2a/exchanges` GET endpoint.

## Locked Decisions (from planning_context)

1. Breaker storage = Valkey, key `a2a:breaker:<from>:<to>`, JSON `{state, failure_count, opened_at}`.
2. TTL = 60s on the failure-count counter (Valkey EXPIRE on each failure write — auto-resets 60s window).
3. Breaker check = inside `send_request()`, BEFORE the PG INSERT. `A2AAgentUnavailableError` on OPEN.
4. State machine: CLOSED → OPEN (3 failures/60s) → HALF_OPEN (60s since opened_at) → CLOSED (probe success) | OPEN (probe fail).
5. Half-open: exactly ONE probe allowed; concurrent calls return `agent_unavailable` while probing.
6. Failure attribution: only `A2ATimeoutError` and `A2AAgentUnavailableError`.
7. Test strategy: state machine simulation with mocked Valkey (no live Valkey required in unit tests).
8. `fakeredis` NOT used — mock at the Valkey client interface level (redis>=5.0 is already in requirements.txt but fakeredis is not in deps).

Implementation notes:
- `get_state()`: Read key → if missing, return STATE_CLOSED. If state == STATE_OPEN and `time.time() - opened_at >= BREAKER_OPEN_DURATION_S`, update state to STATE_HALF_OPEN in Valkey (SET with no TTL — half_open persists until probe outcome) and return STATE_HALF_OPEN.
- `record_failure()`: Use Valkey INCR on `{key}:failures` with EXPIRE BREAKER_WINDOW_S to get failure count within the window. Read main key for current state. If count >= BREAKER_FAILURE_THRESHOLD and state is CLOSED: SET main key to `{"state":"open","failure_count":N,"opened_at":time.time()}` with no TTL (open persists until time check). Return STATE_OPEN. If already OPEN: refresh `opened_at` to now (re-arms the timer). Return STATE_OPEN.
- `record_success()`: If state is HALF_OPEN: DELETE main key and probe-lock key. Return STATE_CLOSED. Else return current state.
- `check_and_allow()`: Call `get_state()`. CLOSED → True. OPEN → False. HALF_OPEN → SETNX `{key}:probe` "1" EX 5 → if SET (nx=True returned) → True (probe allowed) → else False.

Wrap all Valkey calls in try/except Exception with fail-open fallback (return True or STATE_CLOSED on error).

def _check_breaker(from_agent: str, to_agent: str) -> None:
    """Check the per-pair circuit breaker before sending a request.

    Calls check_and_allow(from_agent, to_agent). If the breaker is OPEN
    (or HALF_OPEN with probe lock held), raises A2AAgentUnavailableError
    immediately WITHOUT a PG INSERT.

    Fails open if a2a_breaker module is not importable (graceful degradation).

    Args:
        from_agent: Source agent name.
        to_agent: Target agent name.

    Raises:
        A2AAgentUnavailableError: Breaker is OPEN or HALF_OPEN with probe in flight.
    """
    if not _HAS_BREAKER or check_and_allow is None:
        return  # fail-open: breaker unavailable, allow request

    allowed = check_and_allow(from_agent, to_agent, redis_client=_A2A_REDIS_CLIENT)
    if not allowed:
        raise A2AAgentUnavailableError(
            f"Circuit breaker OPEN for pair ({from_agent}, {to_agent}). "
            "Request blocked without network round-trip.",
            correlation_id=None,
        )
```

def record_a2a_failure(from_agent: str, to_agent: str) -> None:
    """Record an A2ATimeoutError or A2AAgentUnavailableError as a breaker failure.

    Call this when A2ATimeoutError or A2AAgentUnavailableError is caught after
    a send/await cycle. A2APayloadInvalidError and A2AUnknownCapabilityError are
    NOT recorded (caller errors, not target-agent problems — gray-area decision 4).

    Fails silently if breaker module unavailable.
    """
    if not _HAS_BREAKER or record_failure is None:
        return
    try:
        record_failure(from_agent, to_agent, redis_client=_A2A_REDIS_CLIENT)
    except Exception:
        pass  # fail-open


def record_a2a_success(from_agent: str, to_agent: str) -> None:
    """Record a successful A2A exchange as a breaker success.

    Call this after a successful await_response(). Used to close the breaker
    after a HALF_OPEN probe succeeds.

    Fails silently if breaker module unavailable.
    """
    if not _HAS_BREAKER or record_success is None:
        return
    try:
        record_success(from_agent, to_agent, redis_client=_A2A_REDIS_CLIENT)
    except Exception:
        pass  # fail-open
```
