# Plan 23-02: Cache Control Annotations + Metrics Endpoint + Integration Tests

## Objective

Create the infrastructure for tracking prompt prefix cache performance. Since GSD-Amauta does not make direct Claude API calls (Claude Code handles that), this plan focuses on:

1. A Python module (`services/prompt_cache.py`) that provides `cache_control` annotation utilities and cache performance tracking
2. A daemon endpoint (`/metrics/cache`) that surfaces cache hit/miss metrics
3. A daemon endpoint (`POST /metrics/cache/record`) that accepts cache telemetry from Claude Code sessions
4. CLI integration for viewing cache statistics
5. Comprehensive tests for both the module and endpoint

**Architectural context:** Claude Code automatically applies prompt caching based on content stability. It exposes `cache_read_input_tokens` and `cache_creation_input_tokens` in API response usage data. Our metrics infrastructure tracks these values as they are reported back to the daemon, providing visibility into whether the prompt restructuring (Plan 23-01) is actually producing cache hits.

The `annotate_cache_control` function is not called at API time (we do not control Claude Code's API client). Instead, it:
1. Validates that a set of prompt sections has the correct stable/variable ordering
2. Returns metadata about where `cache_control: {"type": "ephemeral"}` SHOULD be placed (useful for documentation and future direct-API integrations in Phase 24)
3. Serves as the programmatic equivalent of the audit script, callable from Python code

## Verification Criteria

1. `python3 -c "from services.prompt_cache import annotate_cache_control, PromptCacheMetrics; print('OK')"` succeeds
2. `curl -s localhost:18799/metrics/cache` returns valid JSON with all 6 required fields
3. After POSTing 3 cache records via `/metrics/cache/record`, `GET /metrics/cache` returns updated counters
4. `node scripts/audit-prefix-stability.cjs` still exits 0 (no regression)
5. `python3 -m pytest tests/test_prompt_cache.py -v` exits 0
6. `node --test tests/23-cache-metrics.test.cjs` exits 0

    ```python
    import threading

    class PromptCacheMetrics:
        """Track prompt cache hit/miss metrics.

        Thread-safe — safe to use from daemon request handlers.
        """
        def __init__(self):
            self._lock = threading.Lock()
            self._cache_read_tokens = 0      # Tokens served from cache (hits)
            self._cache_creation_tokens = 0  # Tokens written to cache (misses/new)
            self._total_requests = 0         # Total API calls recorded

        def record(self, cache_read_input_tokens=0, cache_creation_input_tokens=0):
            """Record cache metrics from a single API call."""
            with self._lock:
                self._cache_read_tokens += cache_read_input_tokens
                self._cache_creation_tokens += cache_creation_input_tokens
                self._total_requests += 1

        def stats(self):
            """Return current cumulative stats.

            Returns:
                dict with:
                    - hit_rate: float (0.0-1.0) — ratio of read tokens to total cached tokens
                    - total_tokens_saved: int — tokens served from cache (= cache_read_tokens)
                    - cost_savings_estimate: float — estimated $ saved (cache reads at 0.1x vs 1.0x)
                    - cache_read_tokens: int — cumulative tokens read from cache
                    - cache_creation_tokens: int — cumulative tokens written to cache
                    - total_requests: int — number of API calls recorded
            """
            with self._lock:
                total_cached = self._cache_read_tokens + self._cache_creation_tokens
                hit_rate = (self._cache_read_tokens / total_cached) if total_cached > 0 else 0.0
                # Cost model: input tokens at $3/MTok (Sonnet), cache read at 0.1x = $0.3/MTok
                # Savings per cached-read token = $3 - $0.3 = $2.7 per MTok
                savings = (self._cache_read_tokens / 1_000_000) * 2.7
                return {
                    "hit_rate": round(hit_rate, 4),
                    "total_tokens_saved": self._cache_read_tokens,
                    "cost_savings_estimate": round(savings, 4),
                    "cache_read_tokens": self._cache_read_tokens,
                    "cache_creation_tokens": self._cache_creation_tokens,
                    "total_requests": self._total_requests,
                }

        def reset(self):
            """Reset all counters (for testing)."""
            with self._lock:
                self._cache_read_tokens = 0
                self._cache_creation_tokens = 0
                self._total_requests = 0
    ```
