## Goal

The PATH collision: when both `npm install -g .` (this package) and `pipx install amauta-ai`
are installed, `amauta` resolves to pipx's binary because pipx prepends `~/.local/bin` before
npm's global bin. The fix has two parts:

1. Detection: `bin/init.cjs` checks for `amauta-ai` on PATH at startup and prints a clear
   warning with remediation steps.
2. Documentation: the install output tells users to use `gsd-amauta` as the canonical command
   (already on PATH via `package.json["bin"]["gsd-amauta"]`), and that `amauta` is an alias
   that may conflict.

`package.json["bin"]` already maps `amauta` to the plugin binary. The collision is not a
code bug — it is a name collision at the OS PATH level. The fix is: detect + warn, and
make the canonical name `gsd-amauta` unambiguous in all documentation.
