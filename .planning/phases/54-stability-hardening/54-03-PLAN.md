## Goal

The `13.1-divergence-protocol.integration.test.cjs` file invokes a real `claude` CLI binary and
requires `ANTHROPIC_API_KEY`. When the key is absent (all forks, fresh environments, all CI
matrix runs via `test.yml`), the test throws `"claude CLI not on PATH"` or API auth failures,
causing CI to fail. The fix: add a guard at the TOP of the test file that checks for
`GSD_LLM_INTEGRATION=true`. When not set, log a single skip message and `process.exit(0)`
BEFORE any `test()` declarations are registered with `node:test` (so the runner sees zero
tests, no errors, no missing-API-key failures).

The behavioral tests workflow (`behavioral-tests.yml`) must be updated to add
`GSD_LLM_INTEGRATION: "true"` — task 54-03-02 does this. The main `test.yml` is intentionally
NOT modified (the skip guard activates by absence of the env var in that workflow, keeping
default CI green).
