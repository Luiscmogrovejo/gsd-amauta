# Plan 59-02 — FIDEL-05: Scope-Width Signal + plan-phase Warning

## Objective

Add a `top_level_dir_width` feature to `complexity_scorer.py`'s
`extract_features` (counting distinct first-path-segments across all
`files_expected` paths), add a `fidelity.scope_width_ceiling` key to
`.planning/config.json`, and emit an operator-visible `scope_width_warning`
field from `cmdInitPlanPhase` when the phase's existing plans span more than
the ceiling. The warning is advisory (the planner can proceed), not a hard
block.

## Verification Criteria

1. `python3 -c "from services.complexity_scorer import extract_features; f = extract_features(None, {'files_expected': ['a/x.py','a/y.py','b/z.py','c/w.py','d/v.py']}); print(f['top_level_dir_width'])"` prints `5`.
2. `.planning/config.json` contains `"fidelity": {"glob_ban": true, "scope_width_ceiling": 4, "post_milestone_reindex": true}`.
3. `node get-shit-done/bin/gsd-tools.cjs init plan-phase 59 --json` returns JSON including a `scope_width_warning` field when the computed phase width exceeds 4.
4. `pytest tests/test_complexity_fidel05.py -v` exits 0.
5. `node --test tests/59-02-fidel05-scope-width.test.cjs` exits 0.

## must_haves

- `FEATURE_KEYS` constant in `complexity_scorer.py` must be extended to
  include `"top_level_dir_width"` — the regression-guard loop at L335 checks
  every key in `FEATURE_KEYS` is present in the returned dict. Add it at the
  end of the list so existing tests that check the 7-key shape get an 8-key
  shape — update those tests if needed.
- `score_features` is NOT changed (the new feature is advisory-only, not
  scored into the 0-100 total). `top_level_dir_width` lives in `extract_features`
  output but is passed through without contributing to the score formula.
- `select_phases` is NOT changed.
- The `scope_width_warning` in `cmdInitPlanPhase` is computed from the plan
  files already present in the phase directory (if any). If no plan files
  exist yet (first plan for the phase), the warning is omitted — the check
  runs post-fact, not pre-fact.
- All default-on: `glob_ban: true`, `scope_width_ceiling: 4`,
  `post_milestone_reindex: true` in `.planning/config.json`.
- No new pip or npm dependencies.
- Backward-compat: existing callers of `extract_features` that expect exactly
  7 keys will now get 8. This is not a breaking change (dict has extra key)
  but if any test uses `assert features.keys() == set(FEATURE_KEYS_OLD)` it
  must be updated.

    **Step 2 — Scan existing plan files for top-level-dir width.**

    After the `phaseInfo` resolution block and BEFORE the `result = {...}` at
    L192, add logic to compute `scopeWidthWarning`:

    ```js
    let scopeWidthWarning = null;
    if (phaseInfo && phaseInfo.directory) {
      const phaseDirFull = path.join(cwd, phaseInfo.directory);
      const topDirs = new Set();
      try {
        const planFiles = fs.readdirSync(phaseDirFull).filter(f => f.endsWith('-PLAN.md') || f === 'PLAN.md');
        for (const pf of planFiles) {
          const pfPath = path.join(phaseDirFull, pf);
          try {
            const content = fs.readFileSync(pfPath, 'utf-8');
            // Extract file paths from all <files_expected> blocks (same pattern as complexity_scorer.py)
            const feBlocks = content.match(/<files_expected>([\s\S]*?)<\/files_expected>/gi) || [];
            for (const block of feBlocks) {
              const lines = block.split('\n');
              for (const line of lines) {
                const stripped = line.trim();
                if (stripped.startsWith('- ') && !stripped.startsWith('- []')) {
                  const candidate = stripped.slice(2).trim();
                  if (candidate && !candidate.endsWith(':') && candidate !== '[]') {
                    const parts = candidate.replace(/\\/g, '/').split('/');
                    if (parts.length >= 2) topDirs.add(parts[0]);
                  }
                }
              }
            }
          } catch {}
        }
      } catch {}
      if (topDirs.size > scopeWidthCeiling) {
        scopeWidthWarning = `SCOPE_WIDTH_WARNING: Phase ${phase} spans ${topDirs.size} top-level dirs (${[...topDirs].sort().join(', ')}), exceeding the ceiling of ${scopeWidthCeiling}. Consider splitting into narrower plans.`;
      }
    }
    ```
