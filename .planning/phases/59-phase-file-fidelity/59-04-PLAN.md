# Plan 59-04 — FIDEL-03: Post-Milestone Reindex Hook + Staleness Citation Scan

## Objective

FIDEL-03 has two halves:

(a) **Reindex hook:** after `milestone complete` runs in `lib/milestone.cjs`,
trigger a non-blocking reindex of the codebase via the existing `reindex`
CLI command (L3181 in `gsd-tools.cjs`, which already posts to
`/reindex` on the RLM service at port 18798). The hook runs fire-and-forget
(non-blocking) with a WARN-and-continue pattern on any error — milestone
completion never fails because RLM is down.

(b) **Staleness detector:** add a `staleness` subcommand to `gsd-tools.cjs`
that scans recent executor RPETD task notes for file-path citations (lines
starting with `- ` in `<read_first>` and `<files_expected>` blocks from
PLAN.md files under `.planning/phases/`) and flags any cited path that no
longer exists in the working tree via `git ls-files`. Output is a JSON array
of `{planFile, taskId, citedPath, reason: 'not_in_working_tree'}`.

Both halves reuse existing tools: the `reindex` HTTP call already in
`gsd-tools.cjs` and `git ls-files` for working-tree membership checks.

## Verification Criteria

1. `node get-shit-done/bin/gsd-tools.cjs milestone complete --dry-run` (or
   the actual `milestone complete` command) does not fail when RLM is
   unreachable — WARN message is emitted to stderr but exit code is 0.
2. `node get-shit-done/bin/gsd-tools.cjs staleness` runs and exits 0,
   printing a JSON array (possibly empty) of stale citations.
3. `node --test tests/59-04-fidel03-staleness.test.cjs` exits 0.

## must_haves

- The reindex hook in `cmdMilestoneComplete` is non-blocking: fire-and-forget
  via a non-awaited HTTP call or spawned child process. If RLM is down, emit
  a single `[FIDEL-03] post-milestone reindex: RLM unreachable — skipped`
  line to stderr and continue. The milestone result object is NOT modified.
- The `staleness` command scans `.planning/phases/` directories for `*-PLAN.md`
  files. For each plan, it extracts paths from `<read_first>` and
  `<files_expected>` blocks. Then for each path it calls
  `git ls-files <path>` (or equivalent) and flags paths that return empty.
  Exclude paths that start with `.planning/` (they may be archived) and paths
  ending in `.md` that live outside the `tests/` or `services/` trees (docs
  that may be legitimately deleted and superseded).
- The staleness command is `gsd-tools staleness [--phase <N>] [--json]`.
  `--phase` limits the scan to a specific phase directory. `--json` outputs
  raw JSON (default). Without `--json`, prints a human-readable summary.
- Reuse the existing `case 'reindex'` HTTP call pattern (L3181-L3208) — do NOT
  build a new HTTP client.
- No new npm or pip dependencies. No touch to Python files.

    ```js
    // FIDEL-03: post-milestone reindex hook (fire-and-forget)
    // Triggers a non-blocking RLM codebase reindex after milestone close.
    // Gracefully degrades if RLM is unreachable — milestone completion never fails.
    try {
      const http = require('http');
      const rlmPort = parseInt(process.env.GSD_RLM_PORT || '18798');
      const body = JSON.stringify({ path: '.', force: false });
      const req = http.request({
        hostname: '127.0.0.1',
        port: rlmPort,
        path: '/reindex',
        method: 'POST',
        headers: { 'Content-Type': 'application/json', 'Content-Length': Buffer.byteLength(body) },
      }, (res) => {
        let data = '';
        res.on('data', (c) => { data += c; });
        res.on('end', () => {
          // Success — optionally log but do not fail
        });
      });
      req.on('error', () => {
        // RLM unreachable — WARN and continue
        process.stderr.write('[FIDEL-03] post-milestone reindex: RLM unreachable — skipped\n');
      });
      req.write(body);
      req.end();
    } catch (_e) {
      process.stderr.write('[FIDEL-03] post-milestone reindex: error initiating reindex — skipped\n');
    }
    ```

    The `req.on('error')` handler fires asynchronously if the connection is
    refused — this is fire-and-forget. The function returns synchronously
    after the `output` call; the HTTP request runs on the event loop but does
    not block the CLI process.

    Note: `milestone.cjs` currently uses `require('fs')`, `require('path')`.
    The `require('http')` is scoped inside the try block (lazy require is fine
    for Node.js built-in modules).

    ```js
    case 'staleness': {
      // FIDEL-03: citation staleness detector.
      // Scans PLAN.md files under .planning/phases/ for <read_first> and
      // <files_expected> citations; flags any path absent from git ls-files.
      //
      // Usage: gsd-tools staleness [--phase <N>] [--json]
      const phaseFilter = args[args.indexOf('--phase') + 1] !== undefined && args.includes('--phase')
        ? String(args[args.indexOf('--phase') + 1])
        : null;
      const jsonFlag = args.includes('--json') || !args.includes('--human');

      const phasesDir = path.join(cwd, '.planning', 'phases');
      const staleEntries = [];

      // Scan phase directories
      let phaseDirs = [];
      try {
        phaseDirs = fs.readdirSync(phasesDir, { withFileTypes: true })
          .filter(e => e.isDirectory())
          .map(e => e.name);
      } catch (_) {
        phaseDirs = [];
      }

      if (phaseFilter) {
        phaseDirs = phaseDirs.filter(d => d.startsWith(phaseFilter + '-') || d === phaseFilter);
      }

      // Helper: extract cited paths from a PLAN.md block
      function extractCitedPaths(content) {
        const cited = [];
        // From <read_first>...</read_first> blocks
        const rfBlocks = content.match(/<read_first>([\s\S]*?)<\/read_first>/gi) || [];
        for (const block of rfBlocks) {
          for (const line of block.split('\n')) {
            const s = line.trim();
            if (s.startsWith('- ') && !s.startsWith('- []')) {
              // Strip inline comments (e.g. "- path/to/file (L100-L200)")
              const raw = s.slice(2).split(' (')[0].trim();
              if (raw && !raw.endsWith(':')) cited.push(raw);
            }
          }
        }
        // From <files_expected>...</files_expected> blocks
        const feBlocks = content.match(/<files_expected>([\s\S]*?)<\/files_expected>/gi) || [];
        for (const block of feBlocks) {
          for (const line of block.split('\n')) {
            const s = line.trim();
            if (s.startsWith('- ') && !s.startsWith('- []')) {
              const raw = s.slice(2).trim();
              if (raw && !raw.endsWith(':') && raw !== '[]') cited.push(raw);
            }
          }
        }
        return [...new Set(cited)];
      }

      // Helper: check if a path is in the working tree
      function inWorkingTree(filePath) {
        // Skip .planning/**  paths (may be archived/moved) and pure .md paths outside src dirs
        if (filePath.startsWith('.planning/')) return true; // skip — archived paths OK
        try {
          const out = spawnSync('git', ['ls-files', '--error-unmatch', filePath], {
            cwd,
            encoding: 'utf-8',
            timeout: 5000,
          });
          return out.status === 0;
        } catch { return true; } // fail-open on git errors
      }

      // Helper: extract task id from context around a line (best-effort)
      function extractTaskId(content, citedPath) {
        // Walk backwards from the citation to find the nearest task id= attribute
        const idx = content.indexOf(citedPath);
        if (idx === -1) return null;
        const before = content.slice(0, idx);
        const taskMatch = before.match(/<task\s+id="([^"]+)">[^]*$/);
        return taskMatch ? taskMatch[1] : null;
      }

      for (const dirName of phaseDirs) {
        const dirPath = path.join(phasesDir, dirName);
        let planFiles = [];
        try {
          planFiles = fs.readdirSync(dirPath).filter(f => f.endsWith('-PLAN.md') || f === 'PLAN.md');
        } catch { continue; }

        for (const pf of planFiles) {
          const pfFull = path.join(dirPath, pf);
          let content = '';
          try { content = fs.readFileSync(pfFull, 'utf-8'); } catch { continue; }

          const planRelPath = path.relative(cwd, pfFull).replace(/\\/g, '/');
          const cited = extractCitedPaths(content);

          for (const citedPath of cited) {
            if (!inWorkingTree(citedPath)) {
              const taskId = extractTaskId(content, citedPath);
              staleEntries.push({
                planFile: planRelPath,
                taskId,
                citedPath,
                reason: 'not_in_working_tree',
              });
            }
          }
        }
      }

      if (jsonFlag) {
        process.stdout.write(JSON.stringify(staleEntries, null, 2) + '\n');
      } else {
        if (staleEntries.length === 0) {
          process.stdout.write('No stale citations found.\n');
        } else {
          process.stdout.write(`Stale citations found: ${staleEntries.length}\n`);
          for (const e of staleEntries) {
            process.stdout.write(`  ${e.planFile} (${e.taskId || 'unknown'}): ${e.citedPath}\n`);
          }
        }
      }
      break;
    }
    ```

    Place this block AFTER the `case 'reindex':` block (around L3208, before
