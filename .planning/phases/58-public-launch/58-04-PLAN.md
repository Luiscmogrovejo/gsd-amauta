# Plan 58-04: npx gsd-amauta init UX Polish

## Objective

Add UX polish to `bin/init.cjs` — the 7-step Phase 44 installer. PUB-04 is strictly ADDITIVE: the 7-step flow, frozen step names, `--upgrade`/`--uninstall` flags, and exit-code rule are all UNCHANGED. What changes: (1) a `--verbose` flag that controls debug output (current behavior where error detail is always printed becomes verbose-only), (2) per-step friendly prefix messages with Unicode checkmarks on success, (3) error messages translated from raw stack traces to one-liner recovery hints, (4) a final summary line "gsd-amauta installed — run `gsd-amauta doctor` to verify". The `renderStepTable` output after all steps is preserved.

## Path Verification

| Path | Status |
|------|--------|
| `bin/init.cjs` | EXISTS — additive changes only; 7 frozen step names unchanged |

## Frozen Surfaces (DO NOT CHANGE)

The following must remain EXACTLY as they are:

- `buildStepResult(name, status, message, details)` function signature
- Step names: `detect_ides`, `install_skills`, `detect_infra`, `migrations`, `start_daemon`, `verify`, `run_assertions` (install flow), plus the upgrade and uninstall step names
- `renderStepTable(results)` function signature and output format
- `module.exports` export list
- `process.exit(results.some(r => r.status === 'fail') ? 1 : 0)` exit-code rule
- All `--skip-install`, `--skip-daemon`, `--force`, `--yes`, `--tools`, `--force-migrate`, `--json`, `--upgrade`, `--uninstall`, `--dry-run` flags — their behavior is unchanged

## Locked Decisions

1. `--verbose` flag added to `flags` object: `verbose: args.includes('--verbose')`.
2. When `flags.verbose` is false (default): suppress raw Node.js error stack traces in catch blocks; show only the one-liner message + recovery hint.
3. When `flags.verbose` is true: current behavior restored — full error detail printed.
4. Per-step progress: before each step starts (in `makeLog`), emit `[N/7] Step name...` (this already happens). On completion, the step result's `status` controls the prefix: `[✓]` for pass, `[!]` for warn, `[✗]` for fail, `[-]` for skip.
5. Error translation table (exact one-liner + hint per error class):
   - PostgreSQL connection refused → `"PG not reachable — start with: docker compose -f docker/docker-compose.yml up -d"`
   - Python not found → `"Python 3.11+ required — install from https://www.python.org/downloads/"`
   - Migration file not found → `"Migrations directory missing — re-run npm install to restore package files"`
   - Daemon script not found → `"Daemon script missing — re-run npm install to restore package files"`
   - Port 18799 in use → `"Port 18799 in use — stop the conflicting process or set GSD_AMAUTA_PORT"`
   - Permission denied → `"Permission denied — check file permissions or run with appropriate user"`
6. Final summary line: after `renderStepTable`, print: `gsd-amauta installed — run \`gsd-amauta doctor\` to verify` (success case). Already-existing `Ready!` line is replaced with this more actionable message.
7. `--verbose` must be documented in `printHelp()`.

    ```javascript
    /**
     * Translate raw error messages to friendly one-liners with recovery hints.
     * Used in step catch blocks when !flags.verbose.
     * @param {Error|string} err
     * @returns {string} friendly message
     */
    function friendlyError(err) {
      const msg = (err && err.message) ? err.message : String(err);
      if (msg.includes('ECONNREFUSED') || msg.includes('connect ECONNREFUSED')) {
        return 'PG not reachable — start with: docker compose -f docker/docker-compose.yml up -d';
      }
      if (msg.includes('python') && msg.includes('not found') || msg.includes('ENOENT') && msg.includes('python')) {
        return 'Python 3.11+ required — install from https://www.python.org/downloads/';
      }
      if (msg.includes('migrations') && msg.includes('not found') || msg.includes('ENOENT') && msg.includes('migrations')) {
        return 'Migrations directory missing — re-run: npm install -g gsd-amauta';
      }
      if (msg.includes('amauta-daemon') && msg.includes('not found') || msg.includes('ENOENT') && msg.includes('daemon')) {
        return 'Daemon script missing — re-run: npm install -g gsd-amauta';
      }
      if (msg.includes('EADDRINUSE') || msg.includes('address already in use') || msg.includes('18799')) {
        return 'Port 18799 in use — stop the conflicting process or set GSD_AMAUTA_PORT environment variable';
      }
      if (msg.includes('EACCES') || msg.includes('permission denied') || msg.includes('Permission denied')) {
        return 'Permission denied — check file permissions or re-run with appropriate user';
      }
      // Default: first line of message, truncated at 120 chars
      return msg.split('\n')[0].substring(0, 120);
    }
    ```
