## Decisions Made

- **node:test output format:** node --test uses Unicode ✔/✗ characters (not TAP) in text/spec mode. Parser detects individual tests by requiring indent depth >= 2 spaces, skipping suite-level summary lines (no leading whitespace). TAP fallback also included.
- **erfc implementation:** Horner's method from Abramowitz & Stegun 7.1.26. Accurate to ~1.5e-7 across all real x. No npm dependencies — pure Node.js math.
- **degraded definition:** Requires BOTH p < 0.05 (statistical significance) AND delta > 0.01 (>1% net degradation). Prevents false positives from single flaky test flips.
- **Baseline generation:** Run actual suite and parse output rather than hardcoding test names. Keys match exactly what node:test reports.
