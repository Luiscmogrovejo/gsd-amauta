# Plan 15-02 --- Run the Audit

## Goal

Execute the tooling created in Plan 15-01 to produce the Phase 15 audit artifacts.
Run `verify-v26.cjs`, capture `15-AUDIT-REPORT.json`, generate `15-AUDIT-REPORT.md`,
and run the behavioral test suite. This plan writes ZERO new code --- it uses Plan
15-01's output. The audit is expected to find gaps (behavioral test scenarios aborting,
Phase 13.1 missing VERIFICATION.md); those gaps are a successful audit, not a failure.

## Scope

- Execute `node scripts/verify-v26.cjs` from project root
- Capture `15-AUDIT-REPORT.json` and `15-AUDIT-REPORT.md` in the phase directory
- Files touched: only `15-AUDIT-REPORT.json` and `15-AUDIT-REPORT.md`
- Zero new code written

**Not in scope:** Fixing any findings, modifying any tooling, creating new files
beyond the two audit report files.

## Must-Haves

- [ ] `verify-v26.cjs` exits with code 0.
- [ ] `15-AUDIT-REPORT.json` exists at `.planning/milestones/v2.2-phases/15-dogfood/15-AUDIT-REPORT.json`
      and contains entries for ALL 5 DOGFOOD criteria (DOGFOOD-01 through DOGFOOD-05).
- [ ] `15-AUDIT-REPORT.json` field `behavioral_test_results` is populated with
      structured data (even if results show failures or timeout).
- [ ] `15-AUDIT-REPORT.md` exists and is derived from `15-AUDIT-REPORT.json`
      (not independently authored).
- [ ] `15-AUDIT-REPORT.json` field `phases_audited` equals `["10", "11", "12", "13", "13.1", "14"]`.
- [ ] `15-AUDIT-REPORT.json` field `phase_15_excluded_from_audit` is `true`.
- [ ] `15-AUDIT-REPORT.json` field `hygiene_debt_observed` is non-empty.
- [ ] `15-AUDIT-REPORT.json` field `dogfood_ledger_gaps` contains `[3]`.
