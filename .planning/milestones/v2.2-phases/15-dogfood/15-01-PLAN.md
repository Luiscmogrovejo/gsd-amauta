# Plan 15-01 --- Tooling Creation

## Goal

Create the four new files that comprise Phase 15's audit infrastructure: the
main verification script (`verify-v26.cjs`), the RPETD intelligence audit
binary (`audit-rpetd-intelligence.cjs`), the verification workflow, and the
slash command. All files are NEW --- zero modification of existing code files
(CONTEXT.md Q1 hard lock). These tools read the v2.6 pipeline read-only and
produce machine-consumable + human-readable audit output.

## Scope

- `scripts/verify-v26.cjs` --- Node.js end-to-end verification script (DOGFOOD-03)
- `get-shit-done/bin/audit-rpetd-intelligence.cjs` --- standalone binary (DOGFOOD-01)
- `get-shit-done/workflows/verify-rpetd-intelligence.md` --- workflow (DOGFOOD-02)
- `commands/amauta/verify-v26.md` --- slash command (DOGFOOD-04)

**Not in scope:** Running the audit (Plan 15-02), publishing the ledger (Plan 15-03),
modifying any existing `.cjs`, `.py`, or `.md` file.

  <action>
    Create `get-shit-done/bin/audit-rpetd-intelligence.cjs` as a standalone Node.js binary.

    **Structure:**

    1. **Shebang and require block:**
       ```js
       #!/usr/bin/env node
       'use strict';
       const { resolvePhaseDir } = require('./gsd-tools.cjs');
       const { spawnSync } = require('child_process');
       const path = require('path');
       ```

    2. **Accept a single argument: task ID** (e.g., `TK-XXXX` or a local task ID).
       If no argument provided, print usage and exit 1:
       `Usage: audit-rpetd-intelligence.cjs <task_id>`

    3. **Retrieve RPETD content** by calling:
       ```js
       const amautaCjs = path.join(__dirname, 'amauta.cjs');
       const result = spawnSync('node', [amautaCjs, 'show', taskId, '--json'], {
         stdio: ['ignore', 'pipe', 'pipe'],
         timeout: 15000,
         env: { ...process.env }
       });
       ```
       Parse stdout as JSON. If parse fails or exit code non-zero, return an error report.

    4. **Extract RPETD phases** from the `show --json` output. The RPETD content
       lives in the `rpetd` field (object with keys R, P, E, T, D, each containing
       `content` string). If the `rpetd` field is absent or empty, report
       `"task_has_no_rpetd": true`.

    5. **Phase-by-phase checks** (string matching on content):

       **D-phase check:**
       - Look for `WHAT:` or `What:` (case-insensitive grep)
       - Look for `WHY:` or `Why:`
       - Look for `WHEN:` or `When:`
       - Look for `TAGS:` or `Tags:`
       - Verdict: `pass` if all 4 present, `gaps_found` if any missing, with
         `missing_fields` array in evidence

       **E-phase check:**
       - Look for `PRE_EXECUTION_EVIDENCE:` (exact string, case-sensitive)
       - Look for `failure_patterns_queried` or `best_practices_queried` or
         `existing_style_queried` or `security_checklist` (any of these subfields)
       - Verdict: `pass` if PRE_EXECUTION_EVIDENCE block found with at least 1
         subfield, `gaps_found` otherwise

       **T-phase check:**
       - Look for `inherited_success_criteria` (string presence)
       - Look for `EDGE_CASES:` (string presence)
       - Look for `REGRESSION:` (string presence)
       - Verdict: `pass` if all 3 present, `gaps_found` if any missing, with
         `missing_blocks` array in evidence

    6. **Output JSON report** to stdout:
       ```json
       {
         "task_id": "<task_id>",
         "audit_timestamp": "<ISO 8601>",
         "d_phase": { "verdict": "pass|gaps_found", "evidence": [...], "missing_fields": [...] },
         "e_phase": { "verdict": "pass|gaps_found", "evidence": [...] },
         "t_phase": { "verdict": "pass|gaps_found", "evidence": [...], "missing_blocks": [...] },
         "overall_verdict": "pass|gaps_found"
       }
       ```
       Overall verdict is `pass` only if all 3 phases pass.

    7. **Exit code:** 0 always (the report itself carries the verdict; the binary
       should not fail just because an audit found gaps).

    8. **require.main guard:** Wrap the main logic in:
       ```js
       if (require.main === module) { main(); }
       module.exports = { auditTask };
       ```
       So the audit function can be imported by verify-v26.cjs without running the CLI.
  </action>
