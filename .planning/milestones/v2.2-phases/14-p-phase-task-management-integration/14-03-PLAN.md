# Plan 14-03 — Pass 1+2 Registration + Integration Tests

## Goal

Complete the `planToTasks()` implementation by adding Pass 0.5 (story
creation), Pass 1 (task creation via `amauta add task`), and Pass 2
(dependency linking via `amauta link`). Ship the integration test suite that
proves idempotent re-run, mid-flight failure recovery via daemon SIGKILL,
drift detection, and dedup bypass scope — all against a real daemon.

## Scope

- `gsd-tools.cjs`: Fill in the Pass 0.5/1/2 stubs left by Plan 14-02 with
  real subprocess calls to `gsd-amauta.cjs` for story creation, task creation,
  and dependency linking.
- `tests/14-plan-to-tasks.integration.test.cjs`: real-daemon integration tests
  with `spawnDaemon()`/`killDaemon()` helpers, daemon SIGKILL mid-flight
  failure injection, idempotency verification, drift detection, and dedup
  bypass scope.

## Must-Haves

- [ ] Pass 0.5 creates story via `amauta add story` subprocess, extracts ST-ID
      from stdout.
- [ ] Pass 1 creates tasks via `amauta add task` subprocess with `--parent`,
      `--agent`, `--criteria`, `--source plan-to-tasks`, `--from-plan <plan_id>`,
      and `metadata.plan_local_id` set.
- [ ] Pass 2 links dependencies via `amauta link` subprocess.
- [ ] Re-run of same plan creates zero duplicate tasks and zero duplicate links.
- [ ] Pass 1 partial failure (daemon killed after task 3 of 5) + re-run
      completes remaining tasks.
- [ ] Pass 2 partial failure (daemon killed after link 1) + re-run completes
      remaining links.
- [ ] Re-run with title-changed plan halts with `plan_amauta_drift` divergence.
- [ ] `PLAN_REGISTRATION` structured block is returned from `planToTasks()`
      with all fields populated.
- [ ] All integration tests pass.

    ```javascript
    const { spawn, spawnSync, execSync } = require('child_process');
    const TEST_PORT = process.env.GSD_AMAUTA_PORT || '19998';

    function spawnDaemon() {
      // Start daemon on test port
      const daemon = spawn('python3', [
        path.join(REPO_ROOT, 'amauta.py'), 'serve', '--port', TEST_PORT
      ], {
        env: { ...process.env, GSD_AMAUTA_PORT: TEST_PORT },
        stdio: ['ignore', 'pipe', 'pipe'],
        detached: true
      });
      // Wait for daemon to be ready (poll /api/health with max 10 retries, 500ms apart)
      // Return daemon process object
      return daemon;
    }

    function killDaemon(daemon) {
      // SIGKILL — not SIGTERM — to simulate hard failure
      try { process.kill(-daemon.pid, 'SIGKILL'); } catch (e) { /* already dead */ }
    }

    function waitForDaemon(maxRetries = 20, interval = 500) {
      // Poll http://127.0.0.1:${TEST_PORT}/api/health
      for (let i = 0; i < maxRetries; i++) {
        try {
          const res = spawnSync('curl', ['-sf', `http://127.0.0.1:${TEST_PORT}/api/health`], { timeout: 1000 });
          if (res.status === 0) return true;
        } catch (e) {}
        spawnSync('sleep', ['0.5']);
      }
      throw new Error(`Daemon on port ${TEST_PORT} did not start within ${maxRetries * interval}ms`);
    }
    ```
