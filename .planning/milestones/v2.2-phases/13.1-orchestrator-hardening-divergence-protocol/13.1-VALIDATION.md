## Sampling Rate

- **After every task commit:** Run `npm test` (deterministic only — fast feedback)
- **After every plan wave:** Run `npm test` (behavioral deferred — too slow for per-wave)
- **Before `/amauta:verify-work`:** Full suite (`npm test && npm run test:behavioral`) must be green
- **Max feedback latency:** 30 seconds (deterministic); behavioral runs manually/CI
- **Phase 13 incident replay test:** MUST pass in every full-suite run — symbolic acceptance criterion
